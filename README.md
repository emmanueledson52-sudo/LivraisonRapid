# 🚀 LivraisonRapid

Bienvenue sur le projet **LivraisonRapid** ! Il s'agit d'une application web dédiée à la réservation et au suivi de services de livraison rapide.

---

## 📌 À propos du projet

**LivraisonRapid** est conçu pour offrir une interface simple, rapide et intuitive permettant aux utilisateurs de commander des livraisons en quelques clics. 

### 🌟 Fonctionnalités principales
* 📱 **Interface responsive :** Adaptée aux écrans mobiles et ordinateurs.
* ⚡ **Service rapide :** Navigation fluide et optimisée.
* ⚙️ **PWA (Progressive Web App) :** Compatible grâce au fichier `manifest.json`.

---

## 🛠️ Technologies utilisées

* **HTML5** : Structure de la page web.
* **CSS3** : Style et mise en page.
* **JavaScript** : Logique et interactivité.
